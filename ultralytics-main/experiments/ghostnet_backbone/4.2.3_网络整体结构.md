# 4.2.3 网络整体结构

4.1 节、4.2.1 节和 4.2.2 节分别从骨干网络、检测头和动态轻量化三个层面提出了轻量化优化方案。本节将上述三个创新点整合，阐述轻量化网络的整体架构设计，分析各组件之间的协同优化机制，并总结整体架构在参数量、计算量和检测精度之间的平衡策略。

轻量化网络的整体架构遵循“骨干网络轻量化 → 特征融合 → 动态通道激活 → 检测头轻量化”的设计流程。具体而言，输入图像首先经过 GhostNetV2 轻量级骨干网络进行多尺度特征提取，通过 Ghost 卷积和 DFC Attention 机制在保持特征表达能力的前提下显著降低参数量与计算量。GhostNetV2 骨干网络输出 P2/4、P3/8、P4/16、P5/32 四个尺度的特征图，这些特征图随后送入 Neck 部分（DDPG、BiFPN_DWC）进行多尺度特征融合，生成具有丰富语义信息的共享特征表示。共享特征层输出的特征随后经过动态通道激活门控分支，根据输入内容特性预测通道权重并关闭低权重通道，实现运行时层面的动态轻量化。经过通道筛选后的特征分为分类分支与回归分支，分别送入基于 MBConv 的轻量级检测头进行预测：分类分支采用无 SE 的 MBConv 模块，回归分支采用带 SE 的 MBConv 模块（仅前两层），最终输出目标的类别概率分布与旋转边界框参数。【需要图：图 4-6，轻量化网络整体架构图，展示从输入到输出的完整流程及各组件的连接关系】

整体架构的设计遵循“静态轻量化 + 动态轻量化”的协同优化策略。在静态轻量化层面，GhostNetV2 骨干网络通过 Ghost 卷积替代标准卷积，在结构层面实现了参数量与计算量的显著降低；MBConv 检测头通过倒残差结构和深度可分离卷积，进一步压缩了检测头部分的计算开销。在动态轻量化层面，动态通道激活策略根据输入内容特性自适应地关闭冗余通道，在运行时层面实现了计算量的动态调整。静态轻量化与动态轻量化的协同作用使得模型能够在保持检测精度的前提下，实现参数量、计算量和推理速度的全面优化。

各组件之间的协同优化机制体现在多个层面。首先，GhostNetV2 骨干网络输出的多尺度特征与原有 Neck 部分（DDPG、BiFPN_DWC）保持兼容，无需额外的适配工作即可实现无缝对接。其次，动态通道激活门控分支作用于共享特征层，一次门控即可同时作用于分类和回归两条分支，避免了在多个分支中重复插入门控分支带来的额外开销。最后，MBConv 检测头在保持与原有 Neck 输出特征兼容性的同时，通过差异化的设计策略（分类分支无 SE、回归分支带 SE）实现了任务特性的精准适配。这种协同设计既保证了各组件能够充分发挥各自的轻量化优势，又确保了整体架构的完整性和可部署性。

在参数量、计算量和检测精度之间的平衡策略方面，整体架构采用了分层次的优化策略。骨干网络层面，通过 GhostNetV2 替代标准卷积，在保持多尺度特征提取能力的前提下实现参数量与计算量的显著降低；检测头层面，通过 MBConv 替代标准卷积，并根据分类与回归任务的特性差异采用差异化设计，在保持检测精度的前提下进一步压缩计算开销；运行时层面，通过动态通道激活策略根据输入内容自适应调整计算量，在背景占比高的区域实现计算量的显著降低，在目标密集区域保持所有通道激活以确保检测精度。这种分层次的优化策略使得模型能够在不同场景下实现计算效率与检测精度的动态平衡，特别适合在资源受限的边缘设备上进行实时推理。

在 YOLO_DDBC 模型的整体框架下，轻量化网络保持了与原有模型的兼容性。具体而言，Neck 部分仍采用第三章中设计的 DDPG、BiFPN_DWC 等模块，损失函数仍采用 CSL_ProbIoU，仅对 Backbone 和 Head 部分进行轻量化改造。这种设计既保留了 YOLO_DDBC 模型在特征融合和损失函数方面的优势，又通过轻量化改造实现了参数量、计算量和推理速度的全面优化，为后续章节的轻量化实验和性能评估奠定了结构基础。
