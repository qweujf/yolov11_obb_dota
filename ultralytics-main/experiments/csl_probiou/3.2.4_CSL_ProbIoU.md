# 3.2.4 CSL 角度编码与旋转 IoU 损失函数设计

损失函数通过计算预测结果与真实标注之间的差异，指导模型在训练过程中不断学习并优化模型参数。在旋转边界框回归损失中，YOLOv11-OBB 模型采用直接角度回归的方式预测目标旋转角度，通过 Sigmoid 激活函数将网络输出映射到某一固定角度范围，然后使用 L1 损失函数进行角度回归优化。然而，这种直接回归方式在处理旋转目标检测时存在关键问题：角度具有周期性特征，目标框旋转 0° 与 180° 在几何上完全等价，但直接回归损失函数将角度视为普通的数值，无法感知角度的周期性特征。具体而言，假设真实角度为 1°，模型可能预测为 179° 或 1°。虽然从几何角度看，179° 和 1° 仅相差 2°（因为 179° 等价于 -1°，与 1° 相差 2°），但直接回归损失函数会计算 |179° - 1°| = 178°，将其视为一个巨大的误差。这使得模型在训练过程中难以稳定收敛，特别是在角度接近 0° 或 180° 时，模型会在两个等价的角度值之间反复震荡，从而影响最终的检测性能。

针对上述角度预测的周期性不连续问题，Yang 等人提出了圆形平滑标签（Circular Smooth Label, CSL）角度编码方法，将角度回归问题转化为分类问题，有效解决了角度边界不连续问题。CSL 的核心思想是将角度范围划分为 $K$ 个类别，每个类别对应一个角度区间，然后使用高斯窗口对真实角度进行平滑标签编码。具体而言，对于真实角度 $\theta_{gt}$，CSL 首先确定其对应的类别索引 $k$（由 $\theta_{gt}$ 与类别角度间隔确定），然后使用高斯函数对类别 $k$ 及其邻近类别进行平滑标签编码，生成一个 $K$ 维的标签向量 $\mathbf{y} = [y_1, y_2, \ldots, y_K]$，其中第 $i$ 个元素的计算如式(3‑15)所示：

\[
y_i = \exp\left(-\frac{(i - k)^2}{2\sigma^2}\right) \tag{3‑15}
\]

其中 $\sigma$ 为高斯窗口的标准差，控制平滑标签的分布范围。通过这种方式，CSL 将角度预测问题转化为多分类问题，网络输出 $K$ 个类别的 logits，经过 Softmax 激活后得到类别概率分布，最终通过加权平均或 argmax 解码得到预测角度。相比直接回归，CSL 方法具有以下优势：首先，通过分类方式避免了角度边界的不连续问题，因为类别之间不存在周期性边界；其次，高斯平滑标签提供了软监督信号，使得模型能够学习到角度之间的连续性和相似性；最后，分类任务通常比回归任务更容易优化，能够提升角度预测的稳定性和精度。在本改进模型中，针对 DOTA 数据集的特点，类别数 $K = 180$（对应 1° 精度），高斯窗口标准差 $\sigma = 1$，以在精度和计算效率之间取得平衡。

除此之外，旋转目标检测的损失函数设计还面临另一个关键问题：旋转框的重叠计算依赖于准确的角度预测，当角度预测存在误差时，基于该角度构建的旋转框与真实框之间的 IoU 计算也会产生偏差。虽然 YOLOv11-OBB 采用旋转 IoU（Rotated IoU, RIoU）来计算旋转框之间的重叠程度，但传统的几何 RIoU 计算方法（如基于多边形相交的精确计算）存在计算复杂、不可微等问题，难以直接用于梯度反向传播和模型优化。此外，即使角度预测准确，几何 RIoU 对长条形旋转目标（如 DOTA 数据集中的船舶、车辆等）也尤为敏感，微小的角度偏差就可能导致旋转框与真实框的重叠面积大幅下降，从而放大损失震荡，降低训练稳定性。

针对上述旋转 IoU 设计中的计算复杂与梯度不稳定问题，Yang 等人在研究旋转目标检测损失函数时提出了基于高斯 Wasserstein 距离的概率 IoU（Probabilistic IoU, ProbIoU）计算方法。该方法不再直接在几何空间中显式计算两个旋转矩形的交并面积，而是将每个旋转框视为一个在图像平面上的二维高斯分布，通过度量两个高斯分布之间的 2‑Wasserstein 距离来间接表征旋转框的重叠关系。具体而言，ProbIoU 将旋转框 $B = (x, y, w, h, \theta)$ 建模为高斯分布 $\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\Sigma})$，其中均值 $\boldsymbol{\mu} = (x, y)$ 为旋转框的中心点坐标，协方差矩阵 $\boldsymbol{\Sigma}$ 由旋转框的宽度 $w$、高度 $h$ 和旋转角度 $\theta$ 决定，其计算如式(3‑16)所示：

\[
\boldsymbol{\Sigma} = \mathbf{R}(\theta) \begin{pmatrix} w^2/12 & 0 \\ 0 & h^2/12 \end{pmatrix} \mathbf{R}(\theta)^T \tag{3‑16}
\]

其中 $\mathbf{R}(\theta)$ 为旋转矩阵。对于两个旋转框 $B_1$ 和 $B_2$，分别建模为高斯分布 $\mathcal{N}(\boldsymbol{\mu}_1, \boldsymbol{\Sigma}_1)$ 和 $\mathcal{N}(\boldsymbol{\mu}_2, \boldsymbol{\Sigma}_2)$，ProbIoU 首先计算两者之间的 2‑Wasserstein 距离 $W_2$，再将该距离映射为 [0,1] 区间内的相似度度量，从而得到“概率 IoU”，其形式如式(3‑17)所示：

\[
\text{ProbIoU} = 1 - \sqrt{1 - \exp(-W_2^2)} \tag{3‑17}
\]

其中 $W_2^2$ 的计算涉及两个高斯分布的均值距离和协方差矩阵的联合约束，具有闭式解形式，既保证了数值稳定性，又便于在网络中高效实现。与传统几何 IoU 相比，ProbIoU 具有两方面显著优势：一方面，其计算过程完全可微，能够自然融入端到端训练框架，无需借助复杂的近似或数值积分；另一方面，由于高斯分布在空间上具有“模糊”特性，对轻微的角度与尺度偏差更加鲁棒，使得得到的 IoU 曲面更加平滑，有利于缓解长条形目标在训练过程中因角度微扰导致的损失剧烈波动。在本改进模型中，ProbIoU 被用于构建旋转框回归项，通过替代传统的几何 IoU 计算，进一步提升了损失函数对旋转边界框重叠关系的刻画精度与训练稳定性。

基于上述分析，本文提出将 CSL 角度编码与 ProbIoU 旋转框损失相结合，通过 CSL 提升角度预测精度，通过 ProbIoU 提升旋转框回归损失计算的准确性，两者协同作用共同优化旋转目标检测的损失函数设计。具体而言，在角度预测分支，使用 CSL 将角度回归转化为分类问题，网络输出 $K$ 维 logits，经过 Softmax 后得到类别概率分布，使用交叉熵损失或 Focal Loss 进行优化；在旋转框回归分支，使用 ProbIoU 计算预测框与真实框之间的重叠程度，作为 IoU 损失的一部分；最终的总损失函数如式(3‑18)所示：

\[
L_{total} = \lambda_1 L_{iou} + \lambda_2 L_{angle} + \lambda_3 L_{cls} + \lambda_4 L_{dfl} \tag{3‑18}
\]

其中 $L_{iou}$ 为基于 ProbIoU 的旋转框回归损失，$L_{angle}$ 为基于 CSL 的角度分类损失，$L_{cls}$ 为分类损失，$L_{dfl}$ 为分布焦点损失（Distribution Focal Loss），$\lambda_1, \lambda_2, \lambda_3, \lambda_4$ 为各损失项的权重系数。通过这种组合设计，CSL 和 ProbIoU 能够协同作用：CSL 提供更准确的角度预测，为 ProbIoU 计算提供更可靠的角度输入；ProbIoU 提供更准确的旋转框重叠评估，为整体损失函数提供更准确的监督信号，从而共同提升旋转目标检测的性能。
