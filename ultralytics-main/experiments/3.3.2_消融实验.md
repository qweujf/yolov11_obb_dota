# 3.3.2 消融实验

为验证本文提出的 YOLO_DDBC 算法中各改进模块的有效性，本节在 DOTAv2.0 数据集上设计了系统的消融实验，通过逐步添加各改进模块并对比性能变化，定量分析各模块对检测精度、模型复杂度和收敛性能的具体影响。所有实验均采用与 3.3.1 中对比实验一致的训练与评估设置，以保证结果具有可比性。

YOLO_DDBC 包含四个核心改进模块：基于 DCNv4 可变形卷积和坐标注意力的 C3k2_DCA 模块、膨胀深度可分离金字塔门控融合模块 DDPG、动态权重修正双向特征金字塔网络 BiFPN_DWC，以及基于 CSL 角度编码和 ProbIoU 的损失函数优化。消融实验从基线模型（YOLOv11-OBB）出发，依次引入上述模块，记录每一步的性能变化，具体配置如表 3-X 所示。

**表 3-X 消融实验配置表**

| 配置编号 | C3k2_DCA | DDPG | BiFPN_DWC | CSL_ProbIoU | 说明 |
|---------|----------|------|-----------|-------------|------|
| A       | ✗        | ✗    | ✗         | ✗           | 基线模型（YOLOv11-OBB） |
| B       | ✓        | ✗    | ✗         | ✗           | 基线 + C3k2_DCA |
| C       | ✓        | ✓    | ✗         | ✗           | 基线 + C3k2_DCA + DDPG |
| D       | ✓        | ✓    | ✓         | ✗           | 基线 + C3k2_DCA + DDPG + BiFPN_DWC |
| E       | ✓        | ✓    | ✓         | ✓           | 完整 YOLO_DDBC（基线 + 所有模块） |

注：✓ 表示启用该模块，✗ 表示不启用该模块。基于上述配置，**本文实际报告的结果建议至少包括以下几类表格与图像**，用于从整体性能、类别细粒度表现以及可视化三个层面，对各模块的贡献进行系统分析：

- **整体性能对比表**：给出配置 A–E 在 DOTAv2.0 测试集上的 mAP\(_{0.5}\)、mAP\(_{0.5:0.95}\)、参数量（Parameters）、计算量（FLOPs）和推理速度（FPS），并附上相对于基线（配置 A）的提升幅度 ΔmAP。该表用于量化“逐步添加模块”这一过程在精度和计算开销上的全局收益。
- **各类别 AP 变化表**：以 15 个类别为行、配置 A–E 为列，统计各配置在 AP\(_{0.5}\) 下的单类别精度，并可额外给出完整模型相对于基线的 ΔAP。该表有助于分析 C3k2_DCA、DDPG 和 BiFPN_DWC 在小目标（如 small-vehicle）、长条目标（如 bridge、ship）以及密集场景类别上的针对性提升。
- **损失函数对比表**：在结构模块固定的情况下，仅改变损失函数组合（如 baseline、+CSL、+ProbIoU、+CSL+ProbIoU），统计 mAP、平均角度误差和收敛轮数，用于证明 CSL 角度编码和 ProbIoU 对旋转框回归稳定性和精度的贡献。

在图像展示方面，本文建议至少绘制三类典型图像：（1）**消融性能折线图**：以配置编号为横轴、mAP 为纵轴，展示从 A 到 E 的逐步提升趋势，并在图中标注各点对应的 ΔmAP 值，便于读者直观把握“哪一步提升最大”；（2）**代表场景检测结果对比图**：在密集小目标场景、尺度差异明显场景和多角度目标场景中，对比基线和完整 YOLO_DDBC 的检测结果，突出漏检减少、定位更精确等直观变化；（3）**参数量–性能权衡散点图**：以参数量或 FLOPs 为横轴、mAP 提升为纵轴，将配置 A–E 标记在同一坐标系中，用于说明在计算开销可接受的前提下，YOLO_DDBC 能够获得的最佳精度增益。通过上述数值结果与可视化分析的结合，可以较为全面地刻画各改进模块在 YOLO_DDBC 中的实际贡献，为后续章节的定量对比和方法总结提供可靠依据。
