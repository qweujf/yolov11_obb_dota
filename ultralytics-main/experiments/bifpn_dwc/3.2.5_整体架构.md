# 3.2.5 改进模型整体架构

基于上述四个核心改进模块，本文构建了面向 DOTA 数据集的旋转目标检测模型 YOLO_DDBC。YOLO_DDBC 以 YOLOv11-OBB 为基础检测算法，整体架构如图 3-XX 所示。模型包含四个关键设计：基于 DCNv4 可变形卷积和坐标注意力的 C3k2_DCA 模块、膨胀深度可分离金字塔门控融合模块 DDPG、动态权重修正双向特征金字塔网络 BiFPN_DWC，以及基于 CSL 角度编码和 ProbIoU 的损失函数优化。C3k2_DCA 模块帮助网络提取更有效的旋转感知特征并抑制背景干扰；DDPG 模块通过多尺度上下文捕获和门控融合增强小目标特征表达能力；BiFPN_DWC 模块提取多尺度特征的内在关联性，结合卷积网络提取的特征，进一步提升算法对小目标的检测性能；CSL 角度编码和 ProbIoU 损失函数优化旋转框的角度预测和重叠计算，提升训练稳定性和检测精度。
