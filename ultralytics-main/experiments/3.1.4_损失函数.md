# 3.1.4 损失函数

为了平衡分类准确性与定位精度，YOLOv11-OBB 的损失函数通常由三部分组成：目标分类损失 $L_{cls}$、旋转边界框回归损失 $L_{box}$ 和分布焦点损失 $L_{dfl}$。总体损失可表示为：

\[
L = \lambda_{box}L_{box} + \lambda_{cls}L_{cls} + \lambda_{dfl}L_{dfl} \tag{3‑3}
\]

其中 $\lambda_{box}, \lambda_{cls}, \lambda_{dfl}$ 为各部分损失的权重系数。在训练过程中，模型通过最小化公式 3‑3 中的总损失，不断提升对目标的分类与定位能力。

**(1) 分类损失**

分类损失 $L_{cls}$ 采用带 Logits 的二元交叉熵损失，用于优化目标类别的预测，对应正负样本的分类判别，分类损失 $L_{cls}$ 如公式 3‑4 所示：

\[
L_{cls} = -\frac{1}{N_{pos}} \sum_{(i,j) \in P} \sum_{c=1}^{C} y_{ij,c} \log p_{ij,c} \tag{3‑4}
\]

其中 $P$ 为正样本集合，$N_{pos}$ 为正样本数，$y_{ij,c}$ 为 one-hot 形式的真实类别标签，$p_{ij,c}$ 为预测类别概率。YOLOv11-OBB 采用 Task-Aligned Assigner 进行正负样本分配，该机制通过综合考虑分类得分和定位质量来分配正样本，相比传统的 anchor-based 方法，不再需要单独的目标存在性（objectness）损失，分类损失直接约束网络学习目标的类别信息。

**(2) 旋转边界框回归损失**

旋转边界框回归损失 $L_{box}$ 通常基于旋转 IoU（Rotated IoU, RIoU）定义。记预测旋转框为 $\hat{B}$，真实旋转框为 $B$，两者之间的旋转 IoU 记为 $\text{RIoU}(\hat{B}, B)$，则回归损失可写为：

\[
L_{box} = 1 - \text{RIoU}(\hat{B}, B) \tag{3‑6}
\]

或在此基础上加入中心距离、长宽比等几何约束得到更稳定的几何回归损失。旋转 IoU 能更准确地反映旋转框（四边形）的重叠情况，相比传统的 L1 或 L2 损失，能够更好地处理旋转目标的几何特性，提升旋转边界框的回归精度。在 YOLOv11-OBB 中，旋转框回归损失还包含角度预测损失，通过 $1 - \cos(\Delta\theta)$ 的形式对角度预测进行约束，其中 $\Delta\theta$ 为预测角度与真实角度的差值。

**(3) 分布焦点损失**

分布焦点损失（Distribution Focal Loss, DFL）$L_{dfl}$ 是 YOLOv11 引入的损失函数，用于优化边界框距离的分布预测。DFL 将边界框坐标的回归问题转化为分布预测问题，通过预测距离的离散分布而非直接回归坐标值，提升了边界框回归的精度和稳定性。DFL 损失的计算如公式 3‑7 所示：

\[
L_{dfl} = -\sum_{i=0}^{n} \left( (y_{i+1} - y) \log(S_i) + (y - y_i) \log(S_{i+1}) \right) \tag{3‑7}
\]

其中 $y$ 为真实距离值，$y_i$ 和 $y_{i+1}$ 为距离值的上下界，$S_i$ 和 $S_{i+1}$ 为预测分布中对应位置的 softmax 概率。DFL 损失通过优化距离分布的预测，使得模型能够更准确地回归边界框坐标，特别是在小目标检测任务中表现优异。
