# 3.3.1 实验环境与参数设置

为验证本文提出的 YOLO_DDBC 算法在遥感图像旋转目标检测任务中的有效性，所有实验均在 DOTAv2.0 数据集上进行。实验设计包括对比实验和消融实验两部分，旨在定量分析各改进模块对模型检测精度和收敛性能的具体贡献。

实验的软硬件环境配置如表 3-1 所示，该配置能够满足大规模模型训练的计算需求，并确保深度学习框架与 GPU 加速库的良好兼容性。

模型训练阶段，输入图像尺寸统一调整为 1024×1024 像素，以适应 DOTA 数据集中目标尺度分布的特点。训练超参数设置如下：优化器采用带动量的随机梯度下降（Stochastic Gradient Descent, SGD），初始学习率设置为 0.01，动量因子为 0.937，权重衰减系数为 0.0005，模型训练总轮数为 300 个 epoch。为保障模型在训练初期阶段的稳定性，前 3 个 epoch 采用预热训练（warm-up）策略，通过逐步增加学习率的方式，避免模型参数在训练初期发生剧烈波动，从而提升训练过程的稳定性和最终模型的收敛性能。批次大小（batch size）设置为 4，数据加载线程数（workers）设置为 4，以充分利用硬件资源并保证训练效率。
