# 3.3.3 对比实验

为验证本文提出的 YOLO_DDBC 算法在遥感图像旋转目标检测任务中的有效性和先进性，本节在 DOTAv2.0 数据集上将 YOLO_DDBC 与当前主流的旋转目标检测方法进行全面的定量和定性对比。对比实验涵盖基于两阶段检测的经典方法（如 Oriented R-CNN、ReDet）、基于 Transformer 的端到端检测方法（如 RT-DETR-OBB）以及基于单阶段检测的轻量级方法（如 YOLOv8-OBB、YOLOv11-OBB），从检测精度、模型复杂度、推理速度等多个维度进行综合评估。

所有对比方法均采用相同的训练和测试设置：输入图像尺寸为 1024×1024 像素，训练轮数为 300 个 epoch，优化器为 SGD，初始学习率为 0.01，批次大小为 4。为公平对比，本文尽可能采用各方法在 DOTAv2.0 数据集上的官方实现或复现结果，对于无法获取官方结果的方法，采用公开代码库进行复现，并确保训练策略与本文方法保持一致。评价指标采用 DOTAv2.0 数据集官方推荐的 mAP\(_{0.5}\) 和 mAP\(_{0.5:0.95}\)，同时统计参数量（Parameters）、计算量（FLOPs）和推理速度（FPS）以评估模型的效率。
