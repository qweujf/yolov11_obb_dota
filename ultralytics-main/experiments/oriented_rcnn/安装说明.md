# Oriented R-CNN 安装说明

## 问题诊断

如果你遇到 "No module named 'mmcv'" 或类似的导入错误，可能是以下原因：

### 1. Python 环境不一致（最常见）

**症状**：
- 安装时显示：`g:\install_app\anaconda\envs\yolov8_seg\lib\site-packages`
- 运行时显示：`D:\anaconda\python.exe`
- 说明安装和运行使用了不同的 Python 环境

**解决方法**：

#### 方法1：激活正确的 conda 环境（推荐）

```powershell
# PowerShell 中
conda activate yolov8_seg

# 验证环境
python -c "import sys; print(sys.executable)"
# 应该显示：g:\install_app\anaconda\envs\yolov8_seg\python.exe

# 然后安装
pip install mmcv-lite mmengine mmdet mmrotate
```

#### 方法2：在当前环境安装

```powershell
# 查看当前 Python 路径
python -c "import sys; print(sys.executable)"

# 如果显示 D:\anaconda\python.exe，则在这个环境中安装
pip install mmcv-lite mmengine mmdet mmrotate
```

#### 方法3：使用完整路径安装

```powershell
# 使用 yolov8_seg 环境的 pip
g:\install_app\anaconda\envs\yolov8_seg\Scripts\pip.exe install mmcv-lite mmengine mmdet mmrotate

# 使用 yolov8_seg 环境的 python
g:\install_app\anaconda\envs\yolov8_seg\python.exe train.py
```

### 2. 检查已安装的包

```powershell
# 激活环境后
conda activate yolov8_seg

# 检查包
pip list | findstr /i "mmcv mmengine mmdet mmrotate"

# 或者用 Python 检查
python -c "import mmcv; print('mmcv OK')"
python -c "import mmengine; print('mmengine OK')"
python -c "import mmdet; print('mmdet OK')"
python -c "import mmrotate; print('mmrotate OK')"
```

### 3. 完整安装步骤（Windows）

```powershell
# 1. 激活 conda 环境
conda activate yolov8_seg

# 2. 升级构建工具
pip install --upgrade pip setuptools wheel

# 3. 安装 mmcv-lite（推荐，不需要编译）
pip install mmcv-lite

# 4. 安装其他依赖
pip install mmengine mmdet

# 5. 安装 mmrotate
pip install mmrotate

# 6. 验证安装
python -c "from mmrotate.apis import init_detector; print('✅ 安装成功')"
```

### 4. 如果 conda activate 不工作

在 PowerShell 中，可能需要先初始化 conda：

```powershell
# 初始化 conda for PowerShell
conda init powershell

# 关闭并重新打开 PowerShell，然后
conda activate yolov8_seg
```

或者使用 CMD：

```cmd
# 在 CMD 中
conda activate yolov8_seg
pip install mmcv-lite mmengine mmdet mmrotate
```

## 常见错误

### 错误1：`metadata-generation-failed`
- **原因**：Windows 上 mmcv 从源码编译失败
- **解决**：使用 `mmcv-lite` 或预编译的 `mmcv-full`

### 错误2：`No module named 'mmcv'`
- **原因**：Python 环境不一致
- **解决**：确保安装和运行使用同一个 Python 环境

### 错误3：`conda activate` 不工作
- **原因**：PowerShell 未初始化 conda
- **解决**：运行 `conda init powershell` 或使用 CMD
