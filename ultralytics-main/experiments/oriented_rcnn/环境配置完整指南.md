# Oriented R-CNN 环境配置完整指南

## 🎯 推荐环境名称

**环境名称：`oriented_rcnn_mmrotate`**

这个名称清晰体现了：
- `oriented_rcnn` - 项目名称
- `mmrotate` - 使用的框架（MMRotate）

其他可选名称：
- `mmrotate_obb_dota` - 强调框架和任务（OBB + DOTA数据集）
- `oriented_rcnn_py38` - 包含Python版本信息
- `mmrotate_cu118` - 包含CUDA版本信息

---

## 📋 环境要求

### 基础要求
- **Python**: >= 3.8（推荐 3.8-3.11）
- **PyTorch**: >= 1.8.0（推荐 2.0.0+cu118）
- **CUDA**: >= 11.8（如果使用GPU）
- **操作系统**: Windows / Linux / macOS

### 必需依赖
- `mmcv-lite` >= 2.0.0 或 `mmcv-full`（Windows推荐mmcv-lite）
- `mmengine` >= 0.10.0
- `mmdet` >= 2.28.0
- `mmrotate` >= 0.3.0

---

## 🚀 方法1：使用 Conda 创建新环境（推荐）

### Windows (PowerShell)

```powershell
# 1. 创建新环境（Python 3.10）
conda create -n oriented_rcnn_mmrotate python=3.10 -y

# 2. 激活环境
conda activate oriented_rcnn_mmrotate

# 3. 安装 PyTorch（CUDA 11.8版本）
pip install torch==2.0.0 torchvision==0.15.0 torchaudio==2.0.0 --index-url https://download.pytorch.org/whl/cu118

# 4. 验证 PyTorch 安装
python -c "import torch; print(f'PyTorch: {torch.__version__}, CUDA: {torch.version.cuda}')"

# 5. 升级构建工具
pip install --upgrade pip setuptools wheel

# 6. 安装 mmrotate 依赖（Windows推荐使用mmcv-lite）
pip install mmcv-lite mmengine mmdet mmrotate

# 7. 安装其他依赖
pip install numpy>=1.23.0 opencv-python>=4.6.0 pyyaml>=5.3.1 tqdm>=4.64.0 matplotlib>=3.3.0 pillow>=7.1.2 scipy>=1.4.1 pandas>=1.1.4

# 8. 验证安装
cd ultralytics-main/experiments/oriented_rcnn
python check_install.py
```

## ⚠️ 常见问题解决

### 问题1：DLL 加载失败（Windows）

**错误信息**：`DLL load failed while importing _ext`

**解决方案**：

**方案A：使用 mmcv-lite（推荐）**
```powershell
pip uninstall mmcv-full -y
pip install mmcv-lite
```

**方案B：安装 Visual C++ Redistributable**
- 下载：https://aka.ms/vs/17/release/vc_redist.x64.exe
- 安装后重启终端

**方案C：使用兼容版本组合**
```powershell
pip uninstall mmcv-lite mmcv-full mmdet mmrotate mmengine -y
pip install mmcv-full==1.8.0 -f https://download.openmmlab.com/mmcv/dist/cu118/torch2.0.0/index.html
pip install mmengine==0.10.0
pip install mmdet==2.28.2
pip install mmrotate==0.3.4
```

### 问题2：环境不一致

**错误信息**：`No module named 'mmcv'`

**解决方案**：
```powershell
# 确保激活正确的 conda 环境
conda activate oriented_rcnn_mmrotate

# 验证环境
python -c "import sys; print(sys.executable)"

# 在当前环境安装
pip install mmcv-lite mmengine mmdet mmrotate
```

### 问题3：版本不兼容

**解决方案**：使用兼容版本组合
```powershell
pip uninstall mmcv-lite mmcv-full mmdet mmrotate mmengine -y
pip install mmcv-lite>=2.0.0
pip install mmengine==0.10.0
pip install mmdet==2.28.2
pip install mmrotate==0.3.4
```
