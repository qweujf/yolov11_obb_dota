# Oriented R-CNN 远程环境配置指南

## 📋 环境要求总览

### 已安装（基础环境）
- ✅ Python >= 3.8
- ✅ PyTorch 2.0.0+cu118
- ✅ torchvision 0.15.0+cu118
- ✅ torchaudio 2.0.0+cu118

### 需要安装（mmrotate 框架）
- ⚠️ mmcv / mmcv-lite
- ⚠️ mmengine
- ⚠️ mmdet
- ⚠️ mmrotate

### 其他依赖
- numpy
- opencv-python
- pyyaml
- tqdm

## 🚀 快速安装步骤

### 方法1：推荐安装（Windows 远程电脑）

```powershell
# 1. 确保在正确的 Python 环境中
# 如果使用 conda，先激活环境
conda activate yolov8_seg  # 或你的环境名

# 验证当前 Python 环境
python -c "import sys; print(sys.executable)"

# 2. 升级构建工具
pip install --upgrade pip setuptools wheel

# 3. 安装 mmcv-lite（推荐，不需要编译，Windows 友好）
pip install mmcv-lite

# 4. 安装其他依赖
pip install mmengine mmdet

# 5. 安装 mmrotate
pip install mmrotate

# 6. 验证安装
python -c "from mmrotate.apis import init_detector; print('✅ mmrotate 安装成功')"
```

### 方法2：使用预编译的 mmcv-full（如果 mmcv-lite 不够用）

```powershell
# 1. 查看 PyTorch 和 CUDA 版本
python -c "import torch; print(f'PyTorch: {torch.__version__}, CUDA: {torch.version.cuda}')"

# 2. 根据版本安装 mmcv-full（CUDA 11.8 + PyTorch 2.0）
pip install mmcv-full -f https://download.openmmlab.com/mmcv/dist/cu118/torch2.0.0/index.html

# 3. 安装其他依赖
pip install mmengine mmdet mmrotate
```

### 方法3：兼容版本组合（如果遇到 DLL 错误）

```powershell
# 卸载旧版本
pip uninstall mmcv-lite mmcv-full mmdet mmrotate mmengine -y

# 安装兼容版本组合
pip install mmcv-full==1.8.0 -f https://download.openmmlab.com/mmcv/dist/cu118/torch2.0.0/index.html
pip install mmengine==0.10.0
pip install mmdet==2.28.2
pip install mmrotate==0.3.4
```

## ⚠️ 常见问题解决

### 问题1：`No module named 'mmcv'`

**原因**：Python 环境不一致，安装和运行使用了不同的环境

**解决**：
```powershell
# 确保激活正确的 conda 环境
conda activate yolov8_seg

# 验证环境
python -c "import sys; print(sys.executable)"

# 在当前环境安装
pip install mmcv-lite mmengine mmdet mmrotate
```

### 问题2：`DLL load failed while importing _ext`

**原因**：mmcv-full 的 C++ 扩展与当前环境不兼容（Windows 常见）

**解决方案**：

**方案A：使用 mmcv-lite（推荐）**
```powershell
pip uninstall mmcv-full -y
pip install mmcv-lite
```

**方案B：安装 Visual C++ Redistributable**
- 下载：https://aka.ms/vs/17/release/vc_redist.x64.exe
- 安装后重启终端

**方案C：使用兼容版本**
```powershell
pip uninstall mmcv-lite mmcv-full mmdet mmrotate -y
pip install mmcv-full==1.8.0 -f https://download.openmmlab.com/mmcv/dist/cu118/torch2.0.0/index.html
pip install mmdet==2.28.2
pip install mmrotate==0.3.4
```

### 问题3：`metadata-generation-failed`

**原因**：Windows 上 mmcv 从源码编译失败

**解决**：使用 `mmcv-lite` 或预编译的 `mmcv-full`

### 问题4：`conda activate` 不工作

**PowerShell 中**：
```powershell
conda init powershell
# 关闭并重新打开 PowerShell
conda activate yolov8_seg
```

**CMD 中**：
```cmd
conda activate yolov8_seg
```

## 📝 注意事项

1. **环境一致性**：确保安装和运行使用同一个 Python 环境
2. **版本兼容性**：mmcv、mmdet、mmrotate 版本需要兼容
3. **Windows 特殊处理**：Windows 上推荐使用 mmcv-lite，避免编译问题
4. **CUDA 版本**：确保 CUDA 驱动版本 >= 11.8（如果使用 GPU）
5. **数据集格式**：确保 DOTA 数据集按照 mmrotate 要求的格式组织
