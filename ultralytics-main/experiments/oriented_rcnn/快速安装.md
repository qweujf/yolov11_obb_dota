# Oriented R-CNN 快速安装指南

## 🚀 一键安装（推荐）

### Windows (PowerShell)

```powershell
cd ultralytics-main/experiments/oriented_rcnn

# 运行自动安装脚本
.\install_mmrotate.ps1
```

### Linux/Mac

```bash
cd ultralytics-main/experiments/oriented_rcnn

# 添加执行权限
chmod +x install_mmrotate.sh

# 运行自动安装脚本
./install_mmrotate.sh
```

---

## 📝 手动安装步骤

### 1. 确保基础环境

```bash
# 检查 Python 版本（需要 >= 3.8）
python --version

# 检查 PyTorch（需要已安装）
python -c "import torch; print(f'PyTorch: {torch.__version__}, CUDA: {torch.version.cuda}')"
```

### 2. 安装 mmrotate 依赖

#### Windows（推荐使用 mmcv-lite）

```powershell
# 升级构建工具
pip install --upgrade pip setuptools wheel

# 安装 mmcv-lite（推荐，不需要编译）
pip install mmcv-lite

# 安装其他依赖
pip install mmengine mmdet mmrotate
```

#### Linux（可以使用完整版）

```bash
# 升级构建工具
pip install --upgrade pip setuptools wheel

# 安装依赖（Linux 上可以直接安装完整版）
pip install mmcv mmengine mmdet mmrotate
```

### 3. 验证安装

```bash
# 运行检查脚本
python check_install.py

# 或手动验证
python -c "from mmrotate.apis import init_detector; print('✅ 安装成功')"
```

## ⚠️ 常见问题

### 问题：DLL 加载失败（Windows）

**解决方案**：
```powershell
# 方案1：使用 mmcv-lite（推荐）
pip uninstall mmcv-full -y
pip install mmcv-lite

# 方案2：安装 Visual C++ Redistributable
# 下载：https://aka.ms/vs/17/release/vc_redist.x64.exe
```

### 问题：环境不一致

**解决方案**：
```powershell
# 确保激活正确的 conda 环境
conda activate yolov8_seg  # 或你的环境名

# 验证环境
python -c "import sys; print(sys.executable)"

# 在当前环境安装
pip install mmcv-lite mmengine mmdet mmrotate
```
